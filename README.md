# Perfect Skin — превью главной страницы

Статический прототип главной страницы интернет-магазина испанской
космецевтики Perfect Skin (ISSEIMI, GLACÉE Skincare).

## Деплой на Vercel

Фреймворк не нужен — это статический сайт. Vercel развернёт его сам:
1. Import Project → выбрать этот репозиторий.
2. Framework Preset: **Other** (сборка не требуется).
3. Deploy.

`index.html` в корне — точка входа. Видео секции «Бестселлеры» лежат в `media/`.

## Секция «Бестселлеры»

Scroll-scrubbed видео: колёсико перематывает движение руки по товарам,
карточка товара появляется слева. Требует настольный Chrome/Safari
(проигрывание H.264). На телефоне и при prefers-reduced-motion —
статичная лента без видео.
