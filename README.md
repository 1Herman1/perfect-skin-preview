# Perfect Skin — превью главной страницы

Статический прототип главной страницы интернет-магазина испанской
космецевтики Perfect Skin (ISSEIMI, GLACÉE Skincare).

## Деплой на Vercel

Фреймворк не нужен — это статический сайт. Vercel развернёт его сам:
1. Import Project → выбрать этот репозиторий.
2. Framework Preset: **Other** (сборка не требуется).
3. Deploy.

`index.html` в корне — точка входа. Видео секции «Бестселлеры» лежат в `media/`.

## Страницы

| Адрес | Что это |
|---|---|
| `/` | Главная в утверждённой палитре «Старое золото и морская синь» |
| `/palettes` | Витрина: пять цветовых вариантов рядом |
| `/palette-1` … `/palette-5` | Главная в каждой из пяти палитр |
| `/logos` | Витрина: два клиентских варианта логотипа рядом |
| `/logo-1`, `/logo-2` | Главная с каждым из двух логотипов (палитра утверждённая) |

## Цветовые палитры

**Заказчик выбрал вариант 2 «Старое золото и морская синь» — он внедрён в
`index.html` как основа.** Остальные четыре оставлены как есть: они больше не
предлагаются к выбору, но полезны для сравнения, если понадобится вернуться к
обсуждению.

| № | Название | Основа |
|---|---|---|
| 1 | Кобальт и фарфор | насыщенный кобальт на холодном фарфоровом фоне |
| 2 | **Старое золото и морская синь — утверждена** | приглушённое золото old money, мягкие тона |
| 3 | Аптечный свет | белая доминанта, синий точечным акцентом, тёмных поверхностей нет |
| 4 | Молоко и шоколад | тёплое молоко, горький шоколад, карамель |
| 5 | Пудра и слива | мягкая пудровая пастель, глубокий сливово-винный акцент |

Внутри каждого макета справа снизу — переключатель палитр (`.pv-switch`),
он только для превью и в боевую вёрстку не идёт.

### Как менять палитры

Цвет живёт в CSS-переменных блока `:root` файла `index.html` — 11 цветовых
токенов плюс три набора RGB-каналов для полупрозрачностей. Ничего цветного
мимо переменных в вёрстке нет, поэтому смена палитры — это замена одного блока.

```
tools/palettes.json      значения всех пяти палитр
tools/gen-palettes.mjs   собирает palette-1..5.html из index.html + считает контрасты
tools/gen-index.mjs      собирает витрину palettes.html
tools/overrides/         точечные правки под конкретную палитру
```

Если палитре нужны не только другие цвета, но и другое поведение
поверхностей, к ней добавляется файл переопределений: поле `overrides` в
`palettes.json` → имя файла в `tools/overrides/`. Его CSS вставляется
последним в `<style>` и перебивает базовые правила, не задевая остальные
варианты. Так сделан вариант 3: клиент попросил убрать тёмные тона, и все
шесть тёмных поверхностей (верхняя полоса, CTA-плитки, панель категорий 03,
блок «Профессионалам», подвал, фон бестселлеров) переведены в светлые.

Пересобрать после правки `index.html` или палитр:

```bash
node tools/gen-palettes.mjs   # упадёт, если контраст ниже нормы WCAG
node tools/gen-index.mjs
```

Генератор сам проверяет шесть пар на каждую палитру (текст/фон, вторичный
текст/фон, текст кнопки/кнопка, акцент/фон, текст/тёмная секция, текст/бейдж)
и не даёт собрать вариант с контрастом ниже 4.5:1.

## Варианты логотипа

Два варианта, присланные заказчиком. Знак, фавикон и палитра в них одинаковые
— различается только начертание надписи.

| № | Вариант | Отличие |
|---|---|---|
| 1 | Тонкое начертание | разрежённая лёгкая надпись |
| 2 | Жирное начертание | плотная жирная надпись |

Лок-ап общий: золотая монограмма PS засечным шрифтом, вертикальная волосяная
черта, справа название. Строка-дескриптор («Испанская космецевтика» /
«Spanish Cosmeceuticals») по просьбе заказчика из знака убрана. Фавикон —
тёмно-синяя скруглённая плитка с золотой PS, собран SVG прямо в страницу.

Золото знака живёт в двух значениях (`tools/brand.json`): `goldArtwork`
`#D6A75E` — как на присланном лок-апе, применяется на крупной подаче
(витрина); `goldOnLight` `#A87C2F` — тот же тон глубже, для шапки, где знак
ужат до высоты строки и золото лок-апа даёт нечитаемые 1.9:1.

```
tools/brand.json          золото знака и цвета фавикона — единый источник
tools/logo-shared.mjs     общая геометрия знака для макетов и витрины
tools/logos.json          начертания надписи двух вариантов
tools/gen-logos.mjs       собирает logo-1..2.html из index.html
tools/gen-logos-index.mjs собирает витрину logos.html
tools/test-logos.mjs      автотесты знака (структура, начертания, вёрстка, a11y)
```

Пересобрать после правок: `node tools/gen-logos.mjs && node tools/gen-logos-index.mjs`,
проверить: `node tools/test-logos.mjs`.

**Знак сейчас собран шрифтом** (Playfair Display), а не вектором заказчика:
исходных файлов логотипа в репозитории нет, были только скриншоты фирменного
борда. Когда заказчик пришлёт оригинал (SVG/AI/PDF), знак и фавикон
заменяются на настоящую отрисовку — разметка под это уже готова.

## Секция «Бестселлеры»

Закреплённая сцена: при прокрутке на каждом шаге проигрывается ролик с рукой,
держащей товар, а справа от него всплывает карточка товара. Ролик играет один
раз и замирает на последнем кадре — без цикла. Требует настольный
Chrome/Safari (проигрывание H.264). На телефоне каждое видео стартует при
входе своего шага в экран; при `prefers-reduced-motion` — статичная лента.
